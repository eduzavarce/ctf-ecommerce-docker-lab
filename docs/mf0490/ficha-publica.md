# MF0490 — Art i Mar Boot2Root

## Descripción

Reto práctico de seguridad informática basado en una máquina Ubuntu Server que aloja el entorno ficticio de comercio electrónico de Art i Mar. El objetivo es investigar el sistema desde una máquina cliente del laboratorio, obtener acceso limitado al servidor y completar una escalada local hasta alcanzar privilegios de administrador.

## Objetivos

- Enumerar los servicios disponibles en el objetivo asignado.
- Obtener acceso a una cuenta limitada del servidor Ubuntu.
- Localizar la primera flag.
- Investigar el sistema desde esa cuenta y alcanzar privilegios de `root`.
- Localizar la segunda flag.

## Condiciones del laboratorio

- Utiliza la máquina objetivo y la dirección de red asignadas para esta práctica.
- Realiza las pruebas únicamente desde el cliente conectado a la red aislada del laboratorio.
- No escanees ni interactúes con otros equipos o redes.
- La máquina objetivo usa arquitectura ARM64 y está preparada para VMware en Apple Silicon.

No se requieren credenciales previas. No se incluyen aquí vulnerabilidades concretas ni instrucciones de explotación.
